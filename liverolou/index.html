Live Rolou

Live Rolou é um canal de cortes de lives no YouTube: os melhores momentos das transmissões, em vídeos curtos, sempre com crédito e link para a live original.

Este site existe para apresentar a ferramenta interna "Live Rolou Métricas", usada só pelo dono do canal para ler as estatísticas do próprio canal (visualizações, retenção e duração média) pela API do YouTube Analytics e decidir quais cortes funcionam melhor.

A ferramenta não é oferecida ao público, não publica nada e não acessa canais de outras pessoas.
